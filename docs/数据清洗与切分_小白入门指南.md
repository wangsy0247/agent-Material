## 二、为什么要做数据清洗？

### 脏数据对 RAG 的破坏（学术文献场景）

假设一篇论文被 PyPDFLoader 解析后，原始文本长这样：

```


                 J. Phys. Chem. Lett. 2024, 15, 1234−1245

                 Publication Date: January 15, 2024


A Deep Neural Network Potential for Water Confined in Graphene Nanocapillaries


                 John Doe, Jane Smith, et al.



Abstract

We present a deep neural network potential...


Copyright © 2024 American Chemical Society

1234

 1. Introduction 

Water is the most important substance...


                 2. Methods




                 The training dataset consists of 10,000 configurations.


References

[1] Smith, J. et al. Nature 2020, 585, 123.
[2] Johnson, A. et al. Phys. Rev. B 2021, 103, 456.
...
[50] ...
```

**如果不清洗直接切分，会产生什么垃圾 chunk？**

| 脏数据片段 | 切分后变成的 chunk | 危害 |
|-----------|-------------------|------|
| `J. Phys. Chem. Lett. 2024, 15, 1234−1245` | 仅包含期刊名的 chunk | 用户问"water potential"时，这个 chunk 也会参与相似度计算，挤占有效位置 |
| `Copyright © 2024 American Chemical Society` | 纯版权声明 chunk | 与科研内容无关，浪费向量空间 |
| `1234`（孤立页码） | 仅含数字的 chunk | 完全无意义，却占用存储 |
| 参考文献列表 `[1] ... [50]` | 50 个以引用为主的 chunk | 稀释正文语义，检索时容易召回大量无关引用 |
| `\n\n\n\n`（连续换行） | 空 chunk 或极短碎片 | 增加向量库噪音 |

> **业界铁律**：RAG 系统中 70% 的问题出在数据质量上，而不是模型不够强。

## 三、PDF 数据清洗（学术文献特化）

### 3.1 学术 PDF 的脏数据类型

| 类别 | 具体表现 | 例子 | 清洗优先级 |
|------|----------|------|-----------|
| **页眉页脚** | 期刊名、卷号、页码、出版日期 | `J. Phys. Chem. Lett. 2024, 15, 1234−1245` | 🔴 高 |
| **版权信息** | 版权声明、期刊 Logo 文字 | `Copyright © 2024 American Chemical Society` | 🔴 高 |
| **孤立页码** | 单页底部或顶部的数字 | `1234` / `5` / `Page 5 of 10` | 🔴 高 |
| **参考文献块** | 文末大量引用列表 | `[1] Smith, J. Nature 2020...` | 🔴 高 |
| **格式残留** | 多余换行、制表符 | `\n\n\n\n` / `\t\t` | 🟡 中 |
| **OCR/解析错误** | 公式乱码、特殊字符 | `E = \sum_{i<j} U(r_{ij})` 解析失败 | 🟡 中 |
| **图表说明孤立** | 脱离正文的 Figure/Table 标题 | `Figure 1. The potential energy surface.` | 🟡 中 |

### 3.2 PDF 清洗 Pipeline

```
PyPDFLoader.load()
   │
   ▼
Step 1: 编码规范化
   │    └── unicodedata.normalize("NFKC") + 去除零宽字符
   ▼
Step 2: 页眉页脚去除
   │    └── 正则匹配期刊名模式、页码模式
   ▼
Step 3: 版权信息去除
   │    └── 匹配 Copyright ©、All rights reserved 等
   ▼
Step 4: 参考文献块移除
   │    └── 检测 "References" / "Bibliography" / "REFERENCES" 标题，移除后续内容
   ▼
Step 5: 空白规范化
   │    └── \n{3,} → \n\n，去除行首尾空格
   ▼
Step 6: 短碎片过滤
   │    └── 去除 < 30 字符的 Document
   ▼
Step 7: 元数据保留
        └── source、page、cleaned_at 等
```

### 3.3 代码示例：学术 PDF 清洗器

```python
"""
academic_pdf_cleaner.py
学术 PDF 特化清洗器 — 适用于本项目的机器学习势函数文献
"""

import re
import unicodedata
from typing import List
from langchain_core.documents import Document


class AcademicPDFCleaner:
    """学术论文 PDF 专用清洗器。
    
    针对机器学习势函数 / 分子动力学领域文献的特化清洗：
    - 去除期刊页眉页脚（J. Phys. Chem. 等）
    - 去除版权和免责声明
    - 移除参考文献列表
    - 保留正文、公式、图表说明的语义完整性
    """

    # 常见期刊名模式（可根据实际数据扩展）
    JOURNAL_PATTERNS = [
        r'J\.\s*Phys\.\s*Chem\.\s*(?:Lett\.|A|B|C).*?\n',
        r'Phys\.\s*Rev\.\s*(?:Lett\.|B|A|X).*?\n',
        r'Nature\s*(?:Materials|Chemistry|Physics|Communications)?.*?\n',
        r'Science\s*(?:Advances)?.*?\n',
        r'npj\s+Comput\.\s*Mater\.\s*\d+.*?\n',
        r'J\.\s*Chem\.\s*Phys\.\s*\d+.*?\n',
        r'Comput\.\s*Phys\.\s*Commun\.\s*\d+.*?\n',
        r'J\.\s*Comput\.\s*Chem\.\s*\d+.*?\n',
    ]

    # 页码模式
    PAGE_NUMBER_PATTERNS = [
        r'\n?\s*[-–—]\s*\d+\s*[-–—]\s*\n?',
        r'\n?\s*Page\s+\d+\s*(?:of|/)\s*\d+\s*\n?',
        r'\n?\s*第\s*\d+\s*页\s*\n?',
        r'\n\s*\d+\s*\n',  # 孤立的数字行（页码）
    ]

    # 版权模式
    COPYRIGHT_PATTERNS = [
        r'Copyright\s+©.*?\.?\s*\n?',
        r'All\s+rights\s+reserved.*?\n?',
        r'American\s+Chemical\s+Society.*?\n?',
        r'Elsevier\s+B\.V\.\s*.*?\n?',
        r'Springer\s*(?:Nature)?\s*.*?\n?',
        r'Wiley\s*(?:-VCH)?\s*.*?\n?',
        r'Received:\s*\d{1,2}\s+(?:Jan|Feb|Mar|Apr|May|Jun|Jul|Aug|Sep|Oct|Nov|Dec).*?\n',
        r'Accepted:\s*\d{1,2}\s+(?:Jan|Feb|Mar|Apr|May|Jun|Jul|Aug|Sep|Oct|Nov|Dec).*?\n',
        r'Published:\s*\d{1,2}\s+(?:Jan|Feb|Mar|Apr|May|Jun|Jul|Aug|Sep|Oct|Nov|Dec).*?\n',
    ]

    # 参考文献检测
    REFERENCES_HEADERS = [
        r'References\s*\n',
        r'Bibliography\s*\n',
        r'REFERENCES\s*\n',
        r'BIBLIOGRAPHY\s*\n',
        r'Notes\s*and\s*References\s*\n',
        r'Notes\s*\n',
    ]

    def __init__(
        self,
        min_doc_length: int = 30,
        remove_references: bool = True,
        remove_copyright: bool = True,
        remove_page_numbers: bool = True,
    ):
        self.min_doc_length = min_doc_length
        self.remove_references = remove_references
        self.remove_copyright = remove_copyright
        self.remove_page_numbers = remove_page_numbers

    def clean_text(self, text: str) -> str:
        """清洗单个文本字符串。"""
        # Step 1: 编码规范化
        text = unicodedata.normalize("NFKC", text)
        
        # 去除零宽字符
        zero_width_chars = '\u200b\u200c\u200d\ufeff\u2060\u180e'
        for char in zero_width_chars:
            text = text.replace(char, '')

        # Step 2: 去除参考文献块（在去除其他内容之前，避免误匹配）
        if self.remove_references:
            text = self._remove_references_block(text)

        # Step 3: 去除页眉页脚（期刊名）
        for pattern in self.JOURNAL_PATTERNS:
            text = re.sub(pattern, '\n', text, flags=re.IGNORECASE)

        # Step 4: 去除版权信息
        if self.remove_copyright:
            for pattern in self.COPYRIGHT_PATTERNS:
                text = re.sub(pattern, '\n', text, flags=re.IGNORECASE)

        # Step 5: 去除页码
        if self.remove_page_numbers:
            for pattern in self.PAGE_NUMBER_PATTERNS:
                text = re.sub(pattern, '\n', text, flags=re.IGNORECASE)

        # Step 6: 去除多余的 "Downloaded from..." 等在线阅读残留
        text = re.sub(r'Downloaded\s+from\s+.*?\n', '\n', text, flags=re.IGNORECASE)
        text = re.sub(r'http://\S+\s*\n', '\n', text)

        # Step 7: 空白规范化
        text = re.sub(r'\n{3,}', '\n\n', text)  # 3+ 换行 → 2 个
        text = re.sub(r' {2,}', ' ', text)       # 连续空格 → 1 个
        text = '\n'.join(line.strip() for line in text.split('\n'))  # 行首尾去空格

        # Step 8: 去除空行过多的残留
        text = re.sub(r'\n{3,}', '\n\n', text)

        return text.strip()

    def _remove_references_block(self, text: str) -> str:
        """检测并移除参考文献块。"""
        for header_pattern in self.REFERENCES_HEADERS:
            match = re.search(header_pattern, text, flags=re.IGNORECASE)
            if match:
                # 从 "References" 标题开始，移除后续所有内容
                text = text[:match.start()].strip()
                break
        return text

    def clean_documents(self, documents: List[Document]) -> List[Document]:
        """批量清洗 Document 列表。"""
        cleaned = []
        stats = {"input": len(documents), "removed_short": 0, "removed_empty": 0}

        for doc in documents:
            cleaned_text = self.clean_text(doc.page_content)
            
            # 过滤空文档
            if not cleaned_text:
                stats["removed_empty"] += 1
                continue
            
            # 过滤过短文档
            if len(cleaned_text) < self.min_doc_length:
                stats["removed_short"] += 1
                continue

            # 保留元数据，添加清洗标记
            new_metadata = doc.metadata.copy()
            new_metadata["cleaned"] = True
            
            cleaned.append(Document(
                page_content=cleaned_text,
                metadata=new_metadata
            ))

        stats["output"] = len(cleaned)
        print(f"[AcademicPDFCleaner] 输入: {stats['input']} | "
              f"输出: {stats['output']} | "
              f"空文档: {stats['removed_empty']} | "
              f"过短: {stats['removed_short']}")
        return cleaned


# ========== 使用示例 ==========
if __name__ == "__main__":
    # 假设已经从 PyPDFLoader 加载了文档
    # from rag_mcp_server.utils.file_loader import pdf_loader
    # raw_docs = pdf_loader("data/some_paper.pdf")
    
    cleaner = AcademicPDFCleaner(
        min_doc_length=30,
        remove_references=True,
        remove_copyright=True,
    )
    # clean_docs = cleaner.clean_documents(raw_docs)
    pass
```

### 3.4 清洗质量检查

清洗后必须验证，防止"误杀"重要信息。

```python
def inspect_cleaning_quality(raw_docs: List[Document], 
                              clean_docs: List[Document],
                              sample_size: int = 5):
    """抽查清洗前后的对比。"""
    import random
    
    print("=" * 60)
    print("学术 PDF 清洗质量抽查")
    print("=" * 60)
    
    # 统计指标
    avg_raw_len = sum(len(d.page_content) for d in raw_docs) / len(raw_docs)
    avg_clean_len = sum(len(d.page_content) for d in clean_docs) / len(clean_docs)
    
    print(f"\n[统计指标]")
    print(f"文档数: {len(raw_docs)} → {len(clean_docs)}")
    print(f"平均长度: {avg_raw_len:.0f} → {avg_clean_len:.0f} "
          f"({avg_clean_len/avg_raw_len*100:.1f}%)")
    
    # 抽查保留的文档
    samples = random.sample(clean_docs, min(sample_size, len(clean_docs)))
    for i, doc in enumerate(samples, 1):
        print(f"\n--- 样本 {i} ---")
        print(f"来源: {doc.metadata.get('source', 'N/A')}")
        print(f"页码: {doc.metadata.get('page', 'N/A')}")
        print(f"长度: {len(doc.page_content)} 字符")
        print(f"内容预览:\n{doc.page_content[:400]}...")


def auto_quality_check(docs: List[Document]) -> dict:
    """自动化检测清洗后文档的潜在问题。"""
    issues = {
        'empty_content': 0,
        'too_short': 0,
        'encoding_issues': 0,
        'excessive_newlines': 0,
        'journal_header_remaining': 0,
        'copyright_remaining': 0,
    }
    
    for d in docs:
        text = d.page_content
        
        if not text.strip():
            issues['empty_content'] += 1
        if len(text) < 20:
            issues['too_short'] += 1
        if '�' in text or '\ufffd' in text:
            issues['encoding_issues'] += 1
        if text.count('\n') > len(text) / 5:
            issues['excessive_newlines'] += 1
        if re.search(r'J\.\s*Phys\.\s*Chem', text, re.I):
            issues['journal_header_remaining'] += 1
        if re.search(r'Copyright\s+©', text, re.I):
            issues['copyright_remaining'] += 1
    
    return issues
```

## 四、HTML 数据清洗

除了 PDF 文献，未来我们可能还需要处理 HTML 格式的数据源（如网页版补充材料、在线数据库导出的 HTML 报告等）。HTML 的清洗逻辑与 PDF 完全不同。

### 4.1 HTML 数据的典型问题

| 问题类型 | 具体表现 | 对 RAG 的影响 |
|---------|---------|-------------|
| **HTML 标签残留** | `<div>`, `<p>`, `<span>` 等标签混入文本 | 标签文字被向量化，干扰语义 |
| **CSS/JS 代码** | `<style>...</style>`, `<script>...</script>` | 大量无意义代码块存入向量库 |
| **导航栏/页脚** | 网站统一的菜单、版权、备案信息 | 每页重复，严重污染向量库 |
| **广告/弹窗文字** | "立即下载"、"订阅我们" | 与科研内容无关 |
| **评论/社交按钮** | "分享到微博"、"评论区" | 噪音信息 |
| **表格格式混乱** | `<table>` 解析后列对齐丢失 | 结构化数据语义破坏 |
| **URL 泛滥** | 大量 `<a href="...">` 链接 | 分散注意力 |
| **编码问题** | HTML 实体如 `&amp;`, `&lt;`, `&gt;` | 可读性下降 |

### 4.2 HTML 清洗 Pipeline

```
HTML 文件 / URL
   │
   ▼
BeautifulSoup 解析
   │
   ▼
Step 1: 移除脚本和样式
   │    └── <script>, <style>, <noscript>
   ▼
Step 2: 移除导航和页脚
   │    └── <nav>, <footer>, 特定 class/id
   ▼
Step 3: 移除广告和无关元素
   │    └── 特定 class/id 如 "ad", "sidebar", "comment"
   ▼
Step 4: 提取正文内容
   │    └── 保留 <p>, <h1-h6>, <table>, <li>, <pre>
   ▼
Step 5: 标签转文本
   │    └── <p> → \n\n, <li> → "- ", <br> → \n
   ▼
Step 6: 实体解码 + 规范化
   │    └── &amp; → &, 合并空白
   ▼
Step 7: 长度过滤
```

### 4.3 代码示例：HTML 清洗器

```python
"""
html_cleaner.py
HTML 数据清洗器 — 适用于网页补充材料、在线数据库 HTML 报告等
"""

import re
import html
from typing import List, Optional
from langchain_core.documents import Document

try:
    from bs4 import BeautifulSoup, NavigableString
    BS4_AVAILABLE = True
except ImportError:
    BS4_AVAILABLE = False
    print("警告: beautifulsoup4 未安装，HTML 清洗功能不可用")


class HTMLCleaner:
    """HTML 文档专用清洗器。
    
    基于 BeautifulSoup 解析 HTML DOM 树，精确移除噪声元素，
    保留正文语义结构。
    """

    # 默认要移除的标签（完全删除，不保留内容）
    REMOVE_TAGS = [
        'script', 'style', 'noscript', 'iframe', 'canvas',
        'svg', 'video', 'audio', 'embed', 'object',
    ]

    # 默认要移除的结构性元素（完全删除）
    REMOVE_STRUCTURAL = [
        'nav', 'footer', 'header', 'aside',
    ]

    # 常见广告/噪音 class/id 关键词（模糊匹配）
    NOISE_KEYWORDS = [
        'ad', 'ads', 'advertisement', 'banner',
        'sidebar', 'widget', 'popup', 'modal',
        'comment', 'comments', 'disqus',
        'share', 'social', 'follow',
        'breadcrumb', 'pagination',
        'cookie', 'consent', 'gdpr',
        'related', 'recommended', 'suggested',
        'newsletter', 'subscribe', 'mailing',
        'download', 'print', 'toolbar',
    ]

    def __init__(
        self,
        min_text_length: int = 50,
        remove_noise_by_class: bool = True,
        preserve_tables: bool = True,
        preserve_code_blocks: bool = True,
    ):
        if not BS4_AVAILABLE:
            raise ImportError("HTMLCleaner 需要 beautifulsoup4，请执行: pip install beautifulsoup4")
        
        self.min_text_length = min_text_length
        self.remove_noise_by_class = remove_noise_by_class
        self.preserve_tables = preserve_tables
        self.preserve_code_blocks = preserve_code_blocks

    def _is_noise_element(self, tag) -> bool:
        """判断一个元素是否为噪音元素。"""
        if not self.remove_noise_by_class:
            return False
        
        # 检查 class
        classes = tag.get('class', [])
        if isinstance(classes, str):
            classes = [classes]
        class_str = ' '.join(classes).lower() if classes else ''
        
        # 检查 id
        id_str = (tag.get('id') or '').lower()
        
        # 检查是否有噪音关键词
        for keyword in self.NOISE_KEYWORDS:
            if keyword in class_str or keyword in id_str:
                return True
        
        return False

    def _extract_text_from_element(self, element) -> str:
        """从单个元素中提取文本，保留基本格式。"""
        if isinstance(element, NavigableString):
            return str(element)
        
        tag_name = element.name
        if tag_name is None:
            return str(element)
        
        # 块级元素加换行
        block_tags = {'p', 'div', 'section', 'article', 'blockquote',
                      'h1', 'h2', 'h3', 'h4', 'h5', 'h6',
                      'table', 'tr', 'pre'}
        
        # 列表项加前缀
        if tag_name == 'li':
            return '- ' + element.get_text(strip=True) + '\n'
        
        # 表格单元格（表格处理单独做）
        if tag_name in ('td', 'th'):
            return element.get_text(strip=True) + ' | '
        
        # 表格行结束加换行
        if tag_name == 'tr':
            return element.get_text(strip=True) + '\n'
        
        # 标题加标记
        if tag_name in ('h1', 'h2', 'h3', 'h4', 'h5', 'h6'):
            level = tag_name[1]
            text = element.get_text(strip=True)
            return f"\n{'#' * int(level)} {text}\n\n"
        
        # 代码块
        if tag_name in ('pre', 'code'):
            text = element.get_text()
            return f"\n```\n{text}\n```\n"
        
        # 换行标签
        if tag_name == 'br':
            return '\n'
        
        # 段落和通用块级元素
        if tag_name in block_tags:
            text = element.get_text(strip=True)
            return f"\n{text}\n" if text else ''
        
        # 行内元素直接取文本
        return element.get_text(strip=True)

    def clean_html(self, html_content: str) -> str:
        """清洗 HTML 内容，返回纯文本。"""
        soup = BeautifulSoup(html_content, 'html.parser')
        
        # Step 1: 移除 script, style 等标签（完全删除）
        for tag_name in self.REMOVE_TAGS:
            for tag in soup.find_all(tag_name):
                tag.decompose()
        
        # Step 2: 移除导航、页脚等结构性元素
        for tag_name in self.REMOVE_STRUCTURAL:
            for tag in soup.find_all(tag_name):
                tag.decompose()
        
        # Step 3: 根据 class/id 移除噪音元素
        if self.remove_noise_by_class:
            for tag in soup.find_all():
                if self._is_noise_element(tag):
                    tag.decompose()
        
        # Step 4: 提取正文文本
        # 优先从 <main>, <article>, <div role="main"> 中提取
        main_content = None
        for selector in ['main', 'article', '[role="main"]', '.content', '.main-content']:
            main_content = soup.select_one(selector)
            if main_content:
                break
        
        if main_content:
            text = main_content.get_text(separator='\n', strip=True)
        else:
            # 退而求其次，取 body 文本
            body = soup.find('body')
            if body:
                text = body.get_text(separator='\n', strip=True)
            else:
                text = soup.get_text(separator='\n', strip=True)
        
        # Step 5: 后处理
        # HTML 实体解码
        text = html.unescape(text)
        
        # 合并连续空白
        text = re.sub(r'\n{3,}', '\n\n', text)
        text = re.sub(r' {2,}', ' ', text)
        
        # 去除孤立 URL 行
        text = re.sub(r'\nhttps?://\S+\n', '\n', text)
        
        return text.strip()

    def clean_documents(self, documents: List[Document]) -> List[Document]:
        """批量清洗 HTML Document 列表。"""
        cleaned = []
        stats = {"input": len(documents), "removed": 0}

        for doc in documents:
            cleaned_text = self.clean_html(doc.page_content)
            
            if len(cleaned_text) < self.min_text_length:
                stats["removed"] += 1
                continue

            new_metadata = doc.metadata.copy()
            new_metadata["cleaned"] = True
            new_metadata["source_type"] = "html"
            
            cleaned.append(Document(
                page_content=cleaned_text,
                metadata=new_metadata
            ))

        stats["output"] = len(cleaned)
        print(f"[HTMLCleaner] 输入: {stats['input']} | "
              f"输出: {stats['output']} | 过滤: {stats['removed']}")
        return cleaned
```

## 五、数据切分策略

清洗完成后，下一步是切分。本项目已经实现了自定义的 `SemanticTextSplitter`，我们需要理解它的工作原理，并针对不同数据源调整参数。

### 5.1 本项目现有切分器解析

当前切分器位于 `rag_mcp_server/rag/text_spliter.py`：

```python
class SemanticTextSplitter:
    """基于语义相似度的文本分割器。
    
    先用 RecursiveCharacterTextSplitter 做初始切分，然后使用 Embedding 模型
    计算相邻 chunk 的语义相似度。如果相邻 chunk 的相似度超过阈值，则合并它们。
    """
    
    def __init__(
        self,
        chunk_size: int = 1000,
        chunk_overlap: int = 200,
        separator: Optional[list[str]] = None,
        embedding_model: Optional[Embeddings] = None,
        similarity_threshold: float = 0.7,
    ):
        # 默认分隔符：
        # ["\n\n", "\n", ".", "!", "?", "。", "！", "？", " ", ""]
```

**工作流程**：

```
原始文本
   │
   ▼
RecursiveCharacterTextSplitter（粗分）
   │    └── 按 separator 优先级递归切分
   │    └── chunk_size=800, chunk_overlap=100
   ▼
Embedding 模型计算相邻 chunk 相似度
   │
   ├── 相似度 > 0.75 ──► 合并为一个 chunk
   │
   └── 相似度 ≤ 0.75 ──► 保持独立
   ▼
输出最终 chunks
```

**优点**：
- 相比纯字符切分，语义边界更自然
- 适合学术论文这种段落内部语义高度连贯的文本

**成本**：
- 每个 chunk 需要一次 Embedding 调用（虽然代码中做了批量优化 `embed_documents()`）
- 75 篇论文约产生 2000~5000 个初始 chunk，合并后约 1500~3000 个

### 5.2 学术论文的切分建议

学术论文的结构特点：

```
Title
   │
   ├── Abstract（高度概括，独立语义单元）
   ├── Introduction（背景介绍）
   ├── Methods（方法细节，长段落）
   ├── Results（实验结果，多图表）
   ├── Discussion（分析与讨论）
   └── Conclusion（总结，独立语义单元）
```

| 配置项 | 当前值 | 建议值 | 理由 |
|-------|--------|--------|------|
| `chunk_size` | 800 | **1000~1200** | 学术论文方法段落通常较长（训练参数、模拟条件），800 字符容易切断连贯段落 |
| `chunk_overlap` | 100 | **150~200** | chunk_size 增大后，overlap 应同步增大（保持 10%~20% 比例） |
| `separator` | 含中英文标点 | ✅ 保持 | 英文论文以 `.` `!` `?` 切分很合适 |
| `similarity_threshold` | 0.75 | **0.7~0.75** | 学术论文同一 section 内语义一致，可适度合并；若想保留更多细粒度信息，可降至 0.7 |

**特别建议**：

1. **Abstract 应保留完整**：摘要通常 150~300 词，是一个高度内聚的语义单元。如果 chunk_size 设置过小，摘要可能被切断。建议确保 `chunk_size >= 400`（英文词数约等于字符数/6，400 字符约 60~70 词，对摘要足够）。

2. **Methods 段落的处理**：方法段落通常包含连续的实验参数列表，如：
   ```
   The cutoff radius was set to 6 Å. The learning rate 
   started at 0.001 and decayed exponentially. The batch 
   size was 32. The training was performed for 1,000,000 steps.
   ```
   这些句子语义高度相关，应被切分到同一个 chunk 中。semantic 切分策略对此很有效。

3. **图表说明（Caption）的处理**：
   - 理想情况下，图表说明应与引用它的正文段落放在一起
   - 如果清洗后图表说明孤立存在，建议在 metadata 中标注 `"type": "figure_caption"`，检索时可根据需要过滤或加权

### 5.3 HTML 内容的切分建议

HTML 清洗后的纯文本与 PDF 解析后的文本特性不同：

| 特性 | PDF 文献 | HTML 网页 |
|------|---------|----------|
| 段落长度 | 长（学术写作风格） | 短（网页阅读习惯） |
| 标题层级 | 清晰（Abstract → 1. → 2.） | 可能混乱（SEO 标题堆砌） |
| 列表数量 | 少 | 多（导航、特性列表） |
| 表格 | 少，结构化 | 可能很多（数据展示） |

**HTML 切分调整建议**：

```yaml
# 如果是以 HTML 数据为主，建议创建单独的配置
html_chunk_size: 600          # 网页段落短，chunk_size 可略小
html_chunk_overlap: 80        # 对应 overlap
html_separator:               # 优先在标题和列表处切分
  - '\n\n'                    # 段落
  - '\n### '                  # 三级标题（保留 h1/h2 作为 chunk 边界）
  - '\n## '                   # 二级标题
  - '\n# '                    # 一级标题
  - '\n- '                    # 列表项
  - '\n'                      # 换行
  - '. '                      # 句子
  - ' '                       # 单词
  - ''                        # 硬切
```

**为什么 HTML 要单独配置？**

- 网页内容的语义内聚单元通常比学术论文更小
- 网页中的 `<h2>`、`<h3>` 标题是很好的语义边界，应优先在此处切分
- 列表项（`<li>`）通常是独立的特性描述，不应强行合并

## 六、切分后数据抽样与人工评估

切分完成后，不能直接把几千个 chunk 无脑丢进向量库。你需要**抽样检查 chunk 质量**，确保清洗和切分没有出问题。

### 6.1 为什么要抽样评估？

```
切分后可能出现的问题：

1. 【语义断裂】"deep neural network" 被切成 "deep neural" + "network potential"
   └── 用户检索 "deep potential" 时匹配度下降

2. 【噪音残留】页眉没清干净 → chunk 内容是 "J. Phys. Chem. Lett. 2024"
   └── 这个 chunk 会参与所有检索，污染结果

3. 【过度合并】语义切分把 Abstract + Introduction 合并成一个超大 chunk
   └── 信息密度降低，稀释了关键内容

4. 【孤立碎片】图表说明被单独切成一个 chunk，脱离上下文
   └── 检索到这个 chunk 时，用户无法理解 "Figure 3 shows..." 指的是什么

5. 【空 chunk】连续换行导致产生空字符串 chunk
   └── 向量库里有无意义向量
```

> **核心原则**：没有评估的切分 = 蒙着眼开车。可能 90% 的 chunk 很好，但 10% 的坏 chunk 就能严重影响用户体验。

### 6.2 抽样策略

#### 策略一：随机抽样（基础）

```python
import random

def random_sample_chunks(chunks: List[Document], sample_size: int = 50) -> List[Document]:
    """随机抽取 chunk 进行人工检查。"""
    return random.sample(chunks, min(sample_size, len(chunks)))
```

#### 策略二：分层抽样（推荐）

按**来源文件**分层抽样，确保每篇文献都被检查到：

```python
from collections import defaultdict

def stratified_sample_by_source(chunks: List[Document], 
                                 samples_per_source: int = 3) -> List[Document]:
    """按来源文件分层抽样，每篇文献至少抽几个 chunk。"""
    chunks_by_source = defaultdict(list)
    for chunk in chunks:
        source = chunk.metadata.get("source", "unknown")
        chunks_by_source[source].append(chunk)
    
    samples = []
    for source, source_chunks in chunks_by_source.items():
        n = min(samples_per_source, len(source_chunks))
        samples.extend(random.sample(source_chunks, n))
    
    return samples
```

#### 策略三：按长度异常抽样

抽出**过长**和**过短**的 chunk，它们往往有问题：

```python
def sample_by_length_anomaly(chunks: List[Document], 
                              percentile_low: float = 5,
                              percentile_high: float = 95) -> List[Document]:
    """抽样过长和过短的异常 chunk。"""
    lengths = [len(c.page_content) for c in chunks]
    
    low_threshold = sorted(lengths)[int(len(lengths) * percentile_low / 100)]
    high_threshold = sorted(lengths)[int(len(lengths) * percentile_high / 100)]
    
    anomalies = [
        c for c in chunks 
        if len(c.page_content) < low_threshold or len(c.page_content) > high_threshold
    ]
    
    return anomalies
```

#### 策略四：按首尾词抽样（检测断裂）

抽出**以不完整词开头或结尾**的 chunk：

```python
def sample_by_boundary_issues(chunks: List[Document]) -> List[Document]:
    """抽样边界可能断裂的 chunk。
    
    例如：
    - 以 "the"、"a"、"an"、"in"、"of" 结尾 → 可能句子被切断
    - 以 "tion"、"ing"、"ed" 开头 → 可能是单词后半截
    """
    boundary_words_start = ['tion', 'ing', 'ed', 'ly', 'ment', 'ness']
    boundary_words_end = [' the', ' a', ' an', ' in', ' of', ' for', ' with', ' by']
    
    suspicious = []
    for chunk in chunks:
        text = chunk.page_content
        # 检查开头
        first_word = text.split()[0].lower() if text.split() else ''
        if any(first_word.endswith(suffix) for suffix in boundary_words_start):
            suspicious.append(chunk)
            continue
        # 检查结尾
        if any(text.lower().endswith(word) for word in boundary_words_end):
            suspicious.append(chunk)
    
    return suspicious
```

### 6.3 人工评估维度

对抽样的每个 chunk，按以下维度打分（1~5 分）：

| 维度 | 说明 | 5分标准 | 1分表现 |
|------|------|--------|--------|
| **语义完整性** | chunk 是否包含一个完整的语义单元 | 读完这个 chunk 能理解一个完整观点 | 句子被切断，意思不完整 |
| **信息密度** | chunk 中有效信息的比例 | 每句话都有科研价值 | 大量空白、页眉、无关文字 |
| **上下文独立性** | 脱离原文后是否仍能理解 | 无需看上下文就能理解内容 | 出现 "it"、"this method" 等指代 |
| **可读性** | 格式是否清晰、是否残留噪音 | 格式整齐，无残留标签/乱码 | 有 HTML 标签、乱码、过多换行 |
| **边界质量** | chunk 的起止位置是否合理 | 在段落/句子边界处切开 | 在单词中间或公式中间切开 |

### 6.4 自动化评估辅助

人工评估之前，先用脚本自动标记明显有问题的 chunk，减少人工工作量：

```python
def auto_flag_chunks(chunks: List[Document]) -> dict:
    """自动标记可疑 chunk，供人工重点检查。"""
    flags = {
        "too_short": [],
        "too_long": [],
        "likely_header_residual": [],
        "likely_copyright_residual": [],
        "formula_garbage": [],
        "repetitive_content": [],
        "boundary_issues": [],
    }
    
    # 计算全局统计（用于重复检测）
    content_hashes = {}
    
    for i, chunk in enumerate(chunks):
        text = chunk.page_content
        meta = f"[Chunk {i}] {chunk.metadata.get('source', 'N/A')}"
        
        # 过短
        if len(text) < 50:
            flags["too_short"].append((meta, text[:100]))
        
        # 过长（可能是过度合并）
        if len(text) > 3000:
            flags["too_long"].append((meta, text[:200] + "..."))
        
        # 页眉残留
        if re.search(r'J\.\s*Phys|Nature\s*\d|Science\s*\d', text, re.I):
            flags["likely_header_residual"].append((meta, text[:150]))
        
        # 版权残留
        if re.search(r'Copyright|All rights reserved', text, re.I):
            flags["likely_copyright_residual"].append((meta, text[:150]))
        
        # 公式乱码（大量反斜杠+非单词字符）
        if text.count('\\') > 10 and len(text) < 500:
            flags["formula_garbage"].append((meta, text[:150]))
        
        # 重复内容检测
        text_hash = hash(text[:100])
        if text_hash in content_hashes:
            flags["repetitive_content"].append(
                (meta, f"与 Chunk {content_hashes[text_hash]} 重复")
            )
        else:
            content_hashes[text_hash] = i
        
        # 边界问题：以介词/冠词结尾
        if re.search(r'\b(the|a|an|in|of|for|with|by|to|and|or)$', text.lower()):
            flags["boundary_issues"].append((meta, text[-100:]))
    
    return flags


def print_flag_report(flags: dict):
    """打印自动标记报告。"""
    print("\n" + "=" * 60)
    print("Chunk 自动质检报告")
    print("=" * 60)
    
    total_issues = 0
    for category, items in flags.items():
        if items:
            print(f"\n【{category}】发现 {len(items)} 个:")
            for meta, preview in items[:5]:  # 只展示前 5 个
                print(f"  - {meta}")
                print(f"    预览: {preview}")
            if len(items) > 5:
                print(f"    ... 还有 {len(items) - 5} 个未展示")
            total_issues += len(items)
    
    print(f"\n总计标记问题: {total_issues}")
    print("=" * 60)
```

## 七、持续监控方案

评估是一次性的"体检"，监控是长期的"心率监测"。

### 7.1 监控什么？

RAG 系统的数据质量可能随时间漂移：

| 漂移类型 | 表现 | 监控方法 |
|----------|------|---------|
| **Query 漂移** | 用户开始问之前没预料到的问题类型 | 记录 query 日志，定期聚类分析 |
| **文档漂移** | 新增文献的风格/格式与旧文献不同 | 新文档入库前强制走清洗评估 |
| **切分漂移** | chunk 平均长度、数量异常变化 | 每次入库后记录 chunk 统计 |
| **检索质量漂移** | 用户反馈"答非所问"增多 | 收集用户反馈，计算满意度 |

### 7.3 监控 Dashboard 建议

可以用简单的日志 + 文件记录实现轻量级监控：

```python
# monitoring.py - 轻量级监控模块

import json
import time
from datetime import datetime
from pathlib import Path

class RAGDataMonitor:
    """RAG 数据质量轻量级监控器。
    
    将监控数据写入 JSONL 文件，便于后续分析。
    """
    
    def __init__(self, log_dir: str = "logs/rag_monitoring"):
        self.log_dir = Path(log_dir)
        self.log_dir.mkdir(parents=True, exist_ok=True)
        
    def log_ingestion(self, metrics: dict):
        """记录数据入库事件。"""
        record = {
            "event": "ingestion",
            "timestamp": datetime.now().isoformat(),
            **metrics
        }
        self._append_log("ingestion.jsonl", record)
    
    def log_query(self, query: str, retrieved_chunks: list, latency_ms: float):
        """记录查询事件。"""
        record = {
            "event": "query",
            "timestamp": datetime.now().isoformat(),
            "query": query,
            "num_retrieved": len(retrieved_chunks),
            "sources": [c.metadata.get("source") for c in retrieved_chunks],
            "latency_ms": latency_ms,
        }
        self._append_log("queries.jsonl", record)
    
    def log_user_feedback(self, query_id: str, rating: int, comment: str = ""):
        """记录用户反馈。"""
        record = {
            "event": "feedback",
            "timestamp": datetime.now().isoformat(),
            "query_id": query_id,
            "rating": rating,
            "comment": comment,
        }
        self._append_log("feedback.jsonl", record)
    
    def _append_log(self, filename: str, record: dict):
        filepath = self.log_dir / filename
        with open(filepath, 'a', encoding='utf-8') as f:
            f.write(json.dumps(record, ensure_ascii=False) + '\n')
    
    def generate_daily_report(self, date_str: str = None) -> dict:
        """生成日报。"""
        if date_str is None:
            date_str = datetime.now().strftime("%Y-%m-%d")
        
        # 读取当日查询日志
        queries = []
        query_log = self.log_dir / "queries.jsonl"
        if query_log.exists():
            with open(query_log, 'r', encoding='utf-8') as f:
                for line in f:
                    record = json.loads(line)
                    if record["timestamp"].startswith(date_str):
                        queries.append(record)
        
        # 读取当日反馈
        feedbacks = []
        feedback_log = self.log_dir / "feedback.jsonl"
        if feedback_log.exists():
            with open(feedback_log, 'r', encoding='utf-8') as f:
                for line in f:
                    record = json.loads(line)
                    if record["timestamp"].startswith(date_str):
                        feedbacks.append(record)
        
        avg_latency = sum(q["latency_ms"] for q in queries) / len(queries) if queries else 0
        satisfaction = sum(f["rating"] for f in feedbacks) / len(feedbacks) if feedbacks else 0
        
        return {
            "date": date_str,
            "total_queries": len(queries),
            "avg_latency_ms": round(avg_latency, 2),
            "total_feedback": len(feedbacks),
            "satisfaction_rate": round(satisfaction * 100, 1),
        }
```

> **写在最后**
>
> 数据清洗和切分是 RAG 系统的"地基工程"。本项目中，75 篇学术 PDF 的清洗质量直接决定了后续检索和生成的上限。不要指望向量检索或重排序能弥补脏数据带来的问题——**垃圾进，垃圾出（Garbage In, Garbage Out）**。
>
> 建议的执行顺序：
> 1. 先用 `AcademicPDFCleaner` 在 5~10 篇文献上测试清洗效果
> 2. 人工抽查清洗前后的对比，调整正则表达式
> 3. 全量清洗后，用 `SemanticTextSplitter` 切分
> 4. 抽样 50~100 个 chunk 做人工评估
> 5. 根据评估结果调整 `chunk_size` 和 `similarity_threshold`
> 6. 入库并开启监控
> 7. 新增文献时重复以上流程
>
> 这套流程看似繁琐，但一次性投入后，后续新增文献的维护成本会极低。祝你清洗愉快！

## 补充：软件手册 PDF 与学术论文的清洗差异

本项目除学术论文外，还遇到了 `datas/abacus.pdf`（ABACUS 第一性原理计算软件用户手册，362 页）。这类软件手册的清洗策略与学术论文**完全不同**：

| 维度 | 学术论文 | ABACUS 用户手册 |
|------|---------|----------------|
| **页眉页脚** | 有期刊名、页码 | 无明显页眉 |
| **版权信息** | 有 Copyright © | 开源软件，无版权声明 |
| **参考文献** | 文末大量引用列表 | 偶尔出现 `[1] [2]`，数量很少 |
| **代码/命令** | 极少 | **极多**（安装命令、输入文件、脚本） |
| **问答格式** | 无 | **有 FAQ 问答对** |
| **目录页** | 无或简单 | **大量带有点线的目录页** |
| **字体问题** | 通常可正常提取 | **中文 CID 乱码**（`(cid:2)` 等） |

### 软件手册的特化清洗要点

**1. 使用 pdfplumber 提取（而非 PyPDFLoader）**

```python
# pypdf 提取中文是乱码："ჰሰෘԔčABACUS൭Ҩ"
# pdfplumber 提取中文正常："原子算筹（ABACUS）软件使用手册"
import pdfplumber
with pdfplumber.open("abacus.pdf") as pdf:
    text = pdf.pages[0].extract_text()
```

**2. 去除目录页的点线**

```python
# 去除 "2.8.5 示例 . . . . . . . . . . . . . . 57"
re.sub(r"\s+\.{3,}\s*\d+\s*$", "", line)
re.sub(r"\s+(?:\.\s+){2,}\d+\s*$", "", line)
```

**3. 处理 CID 乱码**

```python
# "18(cid:2)18(cid:2)18" → "18×18×18"
cid_map = {"(cid:2)": "×", "(cid:3)": "·", "(cid:4)": "•"}
for cid, replacement in cid_map.items():
    text = text.replace(cid, replacement)
# 未映射的 (cid:\d+) 替换为空格
re.sub(r"\(cid:\d+\)", " ", text)
```

**4. 保留代码块和 FAQ 结构**

软件手册中的代码块（Shell 命令、配置文件）和 FAQ 问答对必须保持格式完整，不应被切断或合并。

### 9.3 ChunkEvaluationPipeline（评估与监控）

**文件位置**：`rag_mcp_server/utils/chunk_evaluator.py`

**功能**：切分后多维度抽样、自动标记可疑 chunk、生成人工评估模板、评估结果记录、监控指标追踪。

**命令行使用**：

```bash
python -m rag_mcp_server.utils.chunk_evaluator \
    --input ./workspace/abacus_cleaned.jsonl \
    --output ./workspace/evaluation \
    --chunk-size 800 \
    --chunk-overlap 100 \
    --sample-size 100 \
    --no-semantic
```

**输出文件**：

| 文件 | 说明 |
|------|------|
| `evaluation_templates.txt` | 人工评估模板（可直接打印分发） |
| `auto_flag_report.json` | 自动质检报告（异常 chunk 列表） |
| `score_template.json` | 评分模板（人工打分后回填） |
| `monitoring/` | 监控日志目录（JSONL 格式） |

**Python API 使用**：

```python
from rag_mcp_server.utils.chunk_evaluator import ChunkEvaluationPipeline
import json

# 加载清洗后的页面
pages = []
with open("./workspace/abacus_cleaned.jsonl") as f:
    for line in f:
        pages.append(json.loads(line))

# 运行评估
pipeline = ChunkEvaluationPipeline(
    chunk_size=800,
    chunk_overlap=100,
    sample_size=100,
    output_dir="workspace/evaluation",
)

# 若不想加载 embedding 模型，可关闭语义切分
pipeline.splitter.use_semantic = False

result = pipeline.run(pages)
print(f"总 chunk 数: {result['total_chunks']}")
print(f"抽样数量: {result['sample_size']}")
print(f"自动标记问题: {result['auto_flag_count']}")
```

**自动标记问题类型**：

| 类型 | 说明 |
|------|------|
| `too_short` | 长度 < 30 字符 |
| `too_long` | 长度 > 3000 字符（可能过度合并） |
| `likely_header_residual` | 疑似页眉/期刊名残留 |
| `likely_copyright_residual` | 疑似版权信息残留 |
| `formula_garbage` | CID 乱码或其他公式残留 |
| `repetitive` | 内容重复 |
| `low_chinese_ratio` | 中文字符比例 < 5% |
| `url_dominant` | URL 占比过高 |

> **写在最后**
>
> 数据清洗和切分是 RAG 系统的"地基工程"。本项目中，75 篇学术 PDF 的清洗质量直接决定了后续检索和生成的上限。不要指望向量检索或重排序能弥补脏数据带来的问题——**垃圾进，垃圾出（Garbage In, Garbage Out）**。
>
> 建议的执行顺序：
> 1. 学术论文：先用 `AcademicPDFCleaner` 在 5~10 篇文献上测试清洗效果
> 2. 软件手册：使用 `SoftwareManualCleaner` + pdfplumber 提取，注意 CID 乱码和目录页
> 3. HTML 数据：使用 `HTMLCleaner` 进行 DOM 级清洗
> 4. 全量清洗后，用 `ChunkEvaluationPipeline` 切分并抽样评估
> 5. 根据评估结果调整 `chunk_size` 和 `similarity_threshold`
> 6. 入库并开启监控
> 7. 新增文档时重复以上流程
>
> 这套流程看似繁琐，但一次性投入后，后续新增文献的维护成本会极低。祝你清洗愉快！
