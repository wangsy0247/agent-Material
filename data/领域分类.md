### 1. 新能源电池与储能 (Next-Generation Batteries)

| 体系名称 | 微观模拟特点与难点 | 典型应用场景 |
| :--- | :--- | :--- |
| **固态电解质-电极界面** | 空间电荷层效应复杂，需处理严重的晶格失配和界面化学反应动态过程。 | 全固态锂/钠电池界面阻抗优化 |
| **液态电解质溶剂化鞘** | 需长达纳秒级的分子动力学采样以统计配位原子的交换频率和溶剂化结构。 | 高电压电解液配方设计、快充机制 |
| **正极材料体相脱嵌锂** | 伴随过渡金属变价和强电子关联效应，局部晶格畸变（如 Jahn-Teller 效应）明显。 | 高镍三元、富锂锰基正极循环寿命评估 |
| **硅基负极体积膨胀** | 巨大的体积应变会导致无定形化和键断裂，需要极高鲁棒性的势函数来描述剧烈形变。 | 高比能硅碳负极材料开发 |
| **锂金属负极枝晶生长** | 涉及电场驱动下的离子沉积和金属原子表面扩散，跨尺度特征显著。 | 锂金属电池安全性设计 |
| **固态电解质膜 (SEI) 形成** | 反应网络极其庞大，包含极其复杂的有机-无机杂化组分的分解与聚合。 | 提升电池首次库仑效率与循环稳定性 |
| **固态电解质晶界传输** | 晶界处的原子排列无序，点缺陷富集，寻找低能耗的离子跃迁路径非常困难。 | 氧化物/硫化物固态电解质电导率提升 |
| **正极表面包覆层退化** | 需模拟包覆材料与基体在电化学循环中的元素互扩散和相变剥离过程。 | 长寿命正极表界面修饰工程 |
| **粘结剂-活性物质相互作用** | 涉及软物质（高分子聚合物）与硬物质（无机晶体）的界面粘附力与应力释放计算。 | 极片微观结构力学稳定性分析 |
| **热失控前驱体反应** | 需在极高温度下（>1000K）模拟氧气释放和剧烈的放热化学键断裂，相空间极度非平衡。 | 动力电池本征安全预警与材料阻燃设计 |

### 2. 多相催化与电催化 (Heterogeneous & Electrocatalysis)

| 体系名称 | 微观模拟特点与难点 | 典型应用场景 |
| :--- | :--- | :--- |
| **单原子催化剂配位环境** | 活性中心极度局部化，对载体缺陷高度敏感，需精细处理电荷转移。 | 贵金属减量化、高选择性催化合成 |
| **纳米颗粒表面重构** | 在反应气氛或外加电位下，表面原子会发生动态迁移和重排，构型随时间剧烈演变。 | 工业催化剂真实活性位点溯源 |
| **气-固界面吸附/脱附动力学** | 覆盖度效应（Coverage effect）显著，分子间的侧向相互作用会大幅改变反应能垒。 | 合成氨、二氧化碳加氢制甲醇 |
| **固-液带电界面 (电催化)** | 需要引入隐式/显式溶剂模型和恒电位方法，模拟双电层内的电场分布极其耗时。 | 燃料电池 ORR/OER、电解水制氢 |
| **催化剂毒化与积碳衰减** | 需模拟反应中间体（如 CO 或 C 簇）在活性位点的强吸附和聚合过程。 | 工业催化剂寿命预测与抗毒化设计 |
| **溢流效应 (Spillover)** | 涉及氢等轻原子从金属位点向氧化物载体长距离迁移的动力学路径搜索。 | 储氢材料开发、加氢/脱氢反应优化 |
| **双金属合金表面偏析** | 合金组分在特定气体吸附下会发生趋表效应，需结合蒙特卡洛与 MD 进行构型采样。 | 汽车尾气处理、高效合金催化剂设计 |
| **光催化电子-空穴分离界面** | 涉及激发态动力学与非绝热过程，传统基态 MD 难以直接处理，需耦合非线性响应。 | 太阳能光解水、光催化降解污染物 |
| **沸石分子筛孔道微环境** | 强烈的空间限域效应，客体分子在亚纳米孔道内的扩散动力学受范德华力主导。 | 石油裂解、精细化工产物择形分离 |
| **缺陷介导的反应网络** | 空位或间隙原子的存在会打开全新的低能耗反应通道，需遍历海量的缺陷构型。 | 缺陷工程提升催化本征活性 |

### 3. 半导体与微电子材料 (Semiconductors & Microelectronics)

| 体系名称 | 微观模拟特点与难点 | 典型应用场景 |
| :--- | :--- | :--- |
| **高 k 介电层-硅界面** | 界面态密度（Dit）计算对原子级平整度和悬挂键的钝化极其敏感。 | 先进逻辑芯片栅极结构设计 |
| **掺杂原子的扩散与团簇** | 需计算点缺陷在不同电荷态下的迁移势垒，并模拟高浓度下的杂质聚集。 | 浅结掺杂工艺、半导体良率控制 |
| **二维材料范德华异质结** | 层间耦合极弱但对电子能带影响巨大，需精准的高阶色散力（vdW）修正。 | 下一代低功耗晶体管、光电器件 |
| **相变存储器 (PCM) 结晶动力学** | 需要在极短时间（纳秒级）内模拟非晶态与晶态的快速可逆转变，对势函数要求极高。 | 新型非易失性存储器（如 PCM、忆阻器） |
| **金属互连线电迁移** | 在高电流密度和热应力下模拟金属原子的大规模定向宏观迁移（Kirkendall 效应）。 | 芯片后道互连可靠性与寿命评估 |
| **应变硅中的位错滑移** | 需建立超大体系模型（数万原子以上）以包含完整的位错核结构及其长程应力场。 | 应变工程提升载流子迁移率 |
| **点缺陷的电荷态跃迁** | 涉及带电体系的周期性边界条件修正，以及多重电荷态的形成能精确计算。 | 宽禁带半导体（SiC, GaN）深能级评估 |
| **表面钝化与原子层沉积(ALD)** | 模拟气相前驱体分子在固体表面的半反应、配体消除及成膜生长的逐层过程。 | 纳米级薄膜精密制造工艺优化 |
| **热电材料中的声子散射** | 需精确提取非谐性力常数，评估晶界、纳米析出相对应力波（声子）的强烈散射。 | 高效热电转换与芯片热管理材料 |
| **量子点表面配体交换** | 有机配体与无机纳米晶表面的动态吸附平衡，体系包含大量的 C, H, O, N 元素。 | QLED 显示技术、生物荧光标记 |

### 4. 结构材料与极端合金 (Structural Materials & Alloys)

| 体系名称 | 微观模拟特点与难点 | 典型应用场景 |
| :--- | :--- | :--- |
| **高熵合金 (HEA) 局域化学序** | 组分极其复杂（通常≥5种元素），存在局部短程有序（SRO），相空间极其庞大。 | 航空航天耐高温/高强韧轻质装甲 |
| **裂纹尖端扩展与钝化** | 涉及极端的局部应力集中，原子键被强行撕裂，需评估脆性解理与发射位错的竞争。 | 结构件抗疲劳断裂与损伤容限设计 |
| **晶界滑动与迁移** | 晶界结构多样且动态变化，高温下的剪切耦合迁移需要长时间尺度的动力学演化。 | 高温合金抗蠕变性能优化 |
| **溶质原子在层错处的偏聚** | 需精确描述微量合金元素（如 C, N, B）与扩展位错的强相互作用（Cottrell 气团）。 | 汽车轻量化先进高强钢 (AHSS) 开发 |
| **马氏体相变动力学** | 无扩散的位移型相变，涉及晶格的整体切变，需探索多维势能面上的最小能量路径。 | 形状记忆合金、相变诱导塑性钢 (TRIP) |
| **氢致开裂 (氢脆) 机制** | 氢原子极轻，量子隧穿效应显著，且极易在晶界、位错核富集导致金属键弱化。 | 氢能储运管道与储罐安全性评估 |
| **表面氧化皮生成 (腐蚀)** | 氧原子向金属体相的深度渗透及金属阳离子的向外扩散，伴随巨大的体积膨胀应力。 | 海洋工程、核电包壳材料抗腐蚀设计 |
| **位错与析出相相互作用** | 需模拟位错线切割（Shearing）或绕过（Orowan looping）纳米级沉淀相的动态全过程。 | 铝合金/镁合金时效强化机制 |
| **抗辐射损伤与级联碰撞** | 需使用涵盖排斥势的ZBL势函数，模拟高能粒子轰击瞬间（皮秒级）产生的海量弗伦克尔缺陷。 | 核聚变/裂变反应堆第一壁材料 |
| **非晶合金 (金属玻璃) 剪切带** | 缺乏长程有序结构，塑性变形高度局域化，需追踪原子团簇的重排（STZ 模型）。 | 高弹性极限、抗磨损精密仪器涂层 |

### 5. 分离与多孔功能材料 (Separation & Porous Materials)

| 体系名称 | 微观模拟特点与难点 | 典型应用场景 |
| :--- | :--- | :--- |
| **MOF/COF 气体捕集** | 框架材料具备高度柔性（会发生呼吸效应），需要同时处理骨架形变与客体分子的吸附。 | 碳捕集与封存 (CCS)、有害气体过滤 |
| **二维膜纳米孔道脱盐** | 涉及水分子在亚纳米级孔道内的受限传输，需精确计算离子脱溶剂化的能垒。 | 海水淡化、高效水净化膜设计 |
| **燃料电池质子交换膜** | Grotthuss 机制（质子跳跃）主导，必须使用第一性原理或高精度反应力场（ReaxFF）模拟。 | 质子交换膜燃料电池 (PEMFC) |
| **介孔材料中的手性分离** | 依赖于客体分子与具有手性特征的孔道内壁之间极其微弱的立体位阻与非共价作用。 | 生物制药手性药物拆分与提纯 |
| **聚合物膜的溶胀行为** | 长链高分子的构象熵驱动，需结合粗粒化（CG）和全原子模拟跨越时间/空间尺度。 | 工业废水处理、渗透汽化分离有机物 |
| **超级电容器双电层** | 电极孔隙尺寸与溶剂化离子尺寸相当，导致经典的连续介质理论失效，需全原子推演。 | 高功率密度储能器件孔结构优化 |
| **水凝胶网络-水相互作用** | 涉及极其复杂的氢键网络重构，以及聚合物交联点在水合状态下的动态解离与重组。 | 柔性可穿戴传感器、仿生人造肌肉 |
| **离子液体萃取体系** | 离子液体种类繁多，阴阳离子间静电与色散力交织，液体粘度大导致构型弛豫极慢。 | 稀土元素绿色萃取、核废料分离 |
| **多孔碳材料储氢** | 氢气主要通过弱范德华力物理吸附，需引入量子校正以修正低温下轻原子的零点能。 | 燃料电池车车载高压储氢系统 |
| **渗透能转换流体通道** | 在盐度梯度驱动下，模拟带电纳米孔道内部离子的整流效应（Ion Rectification）。 | 盐差能（蓝色能源）高效收集发电 |

### 6. 极化与磁性量子材料 (Polarization & Quantum Materials)

| 体系名称 | 微观模拟特点与难点 | 典型应用场景 |
| :--- | :--- | :--- |
| **铁电畴壁的移动与反转** | 外电场作用下极化翻转路径多样，需精确映射自发极化强度与原子位移的关系。 | 铁电随机存取存储器 (FeRAM) |
| **压电应变响应** | 需精确提取弹性张量和介电张量，对势函数的能量对位移的二阶导数要求极高。 | 高频超声探测器、微机电系统 (MEMS) |
| **磁性斯格明子 (Skyrmion) 稳定** | 依赖于 Dzyaloshinskii-Moriya (DM) 相互作用，需结合自旋动力学与第一性原理参数化。 | 超高密度、极低功耗自旋电子学器件 |
| **多铁性界面磁电耦合** | 铁磁性与铁电性共存，需处理复杂的电荷转移和界面重构引发的自旋重取向。 | 新型磁电传感器、四态逻辑存储单元 |
| **拓扑绝缘体表面态** | 强自旋-轨道耦合（SOC）体系，体相绝缘但表面导电，极难通过经典势函数有效拟合。 | 容错量子计算、无耗散电子器件 |
| **莫特绝缘体金属-绝缘体转变** | 强关联体系，电子之间的库仑排斥占据主导（Hubbard U），DFT 需进行 +U 修正。 | 神经形态计算器件、智能温控涂层 |
| **挠曲电效应 (Flexoelectricity)** | 应变梯度导致的自发极化，在纳米尺度下极其显著，要求力场能准确捕捉非均匀变形。 | 纳米发电机、无铅生物兼容传感器 |
| **反铁磁自旋动力学** | 净磁矩为零，对外磁场不敏感但存在极高频的自旋共振，需时间步长极短的自旋模拟。 | THz 频段超快自旋振荡器及存储技术 |
| **巨磁阻效应 (GMR) 界面** | 传导电子在磁性层与非磁性层界面的自旋相关散射，对界面粗糙度极度敏感。 | 硬盘高灵敏度磁头、磁性编码器 |
| **相变诱导的发光猝灭** | 晶格受热或应力发生微小相变导致电子能带发生直接/间接带隙切换。 | 压力/温度双响应智能发光防伪材料 |
